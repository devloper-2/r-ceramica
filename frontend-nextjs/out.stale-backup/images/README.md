# images

Place all project images here. Organized by purpose:

```
public/images/
├── hero/        Homepage hero and section background images
├── products/    Product tile and bathroom imagery
├── og/          Open Graph images (1200×630 px)
└── team/        Team and about-page photos
```

> The `og-image.jpg` referenced in `src/app/layout.tsx` should be placed at
> `public/og-image.jpg` (root of public, not in a subfolder) so the metadata
> URL `/og-image.jpg` resolves correctly.
